# CrewMatch

Мобильный прототип знакомств и общения для экипажа круизных судов. Сайт автоматически подключается к подготовленному Supabase-проекту CrewMatch. Анкеты 18+, общий чат, взаимные лайки и личные сообщения хранятся в общей базе.

- Сайт: https://batan25792579-ship-it.github.io/CrewMatch/
- [Регистрация и проверка двух аккаунтов](SUPABASE_SETUP.md)

Клиент находится в `index.html`. SQL для создания **отдельной** копии базы — `supabase.sql` и `supabase-profile-gate.sql`; инструкции по миграции старой схемы — в руководстве выше. Для текущего сайта миграции уже применены.

Это MVP: возраст определяется по введённой дате рождения. Подтверждение личности и работы на судне пока не добавлены.
