# CrewMatch

Мобильный прототип знакомств и общения для экипажа круизных судов. Сайт автоматически подключается к подготовленному Supabase-проекту CrewMatch. Анкеты 18+, до шести фото, рассказы о себе, фильтр по цели знакомства, общий чат, взаимные лайки и личные сообщения хранятся в общей базе.

- Сайт: https://batan25792579-ship-it.github.io/CrewMatch/
- [Регистрация и проверка двух аккаунтов](SUPABASE_SETUP.md)

Клиент находится в `index.html`. SQL для **отдельной** копии базы: `supabase.sql`, затем `supabase-profile-gate.sql`, `supabase-profile-photos.sql` и `supabase-discover-story.sql`. Для текущего сайта миграции уже применены. Порядок и проверка двух аккаунтов — в руководстве выше.


## Жалобы и блокировки

В Discover и личном чате можно пожаловаться на пользователя или заблокировать его. Блокировка скрывает его анкету и запрещает личную переписку в обе стороны; жалоба сохраняется в `public.reports` и **не** отправляет уведомление администратору автоматически.

До появления панели модерации владелец проекта должен регулярно проверять новые записи в Supabase **Table Editor → public.reports** со статусом `open`, принимать решение и менять `status` на `reviewing`, `resolved` или `dismissed`. Не удаляйте сообщения или жалобы без отдельного решения по хранению данных.

Это MVP: возраст определяется по введённой дате рождения. Подтверждение личности и работы на судне пока не добавлены.
