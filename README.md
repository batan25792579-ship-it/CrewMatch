# CrewMatch

Мобильный прототип знакомства и общения круизного экипажа. Реальные учётные записи, анкеты 18+, общий чат, взаимные лайки и личные сообщения работают через Supabase после подключения проекта и выполнения SQL.

- Сайт: https://batan25792579-ship-it.github.io/CrewMatch/
- [Пошаговая настройка Supabase и проверка двух аккаунтов](SUPABASE_SETUP.md)

Код клиента находится в `index.html`. Для новой базы выполните `supabase.sql`, затем `supabase-profile-gate.sql`. Для базы со старой публичной датой рождения следуйте инструкции по миграции.

Это MVP с заявленной пользователем датой рождения. Проверка личности и работы на судне ещё не добавлены.
